# Guía Tutor / Estudiante

**Evidencia:** `[PROMPT-MG-SEC-8-E]`.

### Tutor
- Consultar sus expedientes asignados.
- Registrar reuniones dentro del plazo parametrizado.
- Registrar informes de avance.
- Consultar defensas/calificaciones según permisos.

### Estudiante
- Consultar únicamente sus expedientes.
- Consultar reuniones, documentos y defensas propias.
- Ver calificaciones únicamente cuando estén publicadas.

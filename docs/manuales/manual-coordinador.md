# Manual del Coordinador MG

**Evidencia:** `[PROMPT-MG-SEC-8-E]`.

1. Iniciar sesión con una cuenta de Coordinador MG.
2. Abrir Cohortes/Modalidades/Parámetros y revisar configuración.
3. Abrir Expedientes para consultar fichas y etapas.
4. Asignar o cambiar Tutor desde el expediente.
5. Gestionar tribunales y defensas.
6. Validar reuniones.
7. Revisar Hitos e Informes.
8. Atender Alertas dejando nota.
9. Revisar Dashboard y Reportes.
10. Consultar Bitácora.

Las plantillas institucionales siguen marcadas como provisionales hasta recepción de UPDS.
